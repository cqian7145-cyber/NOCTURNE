# NOCTURNE V3.0 · MEMORIA

本地优先的个人成长与知识学习空间。保留 V2.0 Ascension 的习惯、目标、专注与成长档案，新增知识库、制卡、主动回忆和真实 FSRS 调度。无需账户、后端或外部 AI 服务。

## 在 Windows 本地打开

需要 Node.js 22.12 或更新版本。首次使用：

~~~powershell
npm ci
npm run build
npm run preview -- --host 127.0.0.1 --port 5173 --strictPort
~~~

打开 http://127.0.0.1:5173/。沿用原有协议、主机、端口与浏览器配置文件，才能读取同一份本地记录。开发模式使用 npm run dev。请通过本地服务器使用，直接双击 dist/index.html 无法保证模块和离线功能正常。

## 五分钟开始使用 MEMORIA

1. 在主导航进入 MEMORIA，创建一个卡组。
2. 制卡工坊提供基础问答、双向、编号填空、概念、代码、图片遮挡六种模板。点「继续制作下一张」开始新的笔记。
3. 知识库支持 Markdown 编辑与阅读预览、公式、代码高亮、本地上传或粘贴图片、来源与标签、父子节点、收藏、归档、回收站、版本对照和恢复。
4. 正文使用「问题 >> 答案」「词语 <> 释义」「{{c1::答案::提示}}」并同步卡片。代码围栏中的语法不会制卡。相同来源块及模板的修改保留卡片记忆，删除来源后重新创建会成为新的来源。
5. 从学习中心开始回忆。Space 揭晓，1–4 评分，Ctrl/⌘ Z 撤销，E 编辑，S 暂停卡片，Esc 暂停会话。先揭晓后才允许评分。学习间隔未到时可退出，稍后恢复。
6. 在学习设置调整每日数量、目标保留率、学习步长和每轮时间。每日数量上限不隐藏积压；可显式临时突破上限。

## 保留的 V2 成长系统

每日二值或量化打卡、最低标准、部分完成、跳过原因、弹性周次数、暂停区间、历史补卡、例行组合、人生领域、目标树及依赖、里程碑、番茄与正计时、沉浸与环境音、完成率和热力图、同期对比、习惯相关性、成长编年史、日周月季年复盘、命令中心、三种主题与减少动效。

习惯连续记录按计划日计算，暂停日不计失败。弹性周目标按实际执行及时累计，在周结算时分配遗漏。相关性只表示共同变化。目标有里程碑时，行动占 75%，里程碑占 25%；前置目标会阻止下游目标达成。

## 学习数据口径

- 使用真正的 ts-fsrs@5.4.2，不用自制倍增间隔替代。每条评分保存算法版本、当时参数、评分前后记忆状态。四档预览使用当前卡组的实际保留率。
- 新卡、学习、Review 和重学各自保留状态。成熟卡定义为当前 Review 且稳定性至少 21 天。
- 实际回忆率的分母仅为正式、已经到期的 Review 卡评分，困难/记得/轻松为成功。新卡、学习、重学、练习、模拟考试、撤销和未采用的分叉日志均不计入。
- 预测可回忆率由 FSRS 估计。未来 14 天图按当前到期时间分桶，今天包含积压，不模拟尚未发生的评分。
- 练习和考试模式保留练习日志，不更新正式 FSRS 或正式学习统计。
- 自动习惯标记来源为 memoria，手工记录为 manual。手工填写的记录始终保留；撤销评分重算原评分所在日期。每个习惯最多启用一条联动规则。
- 学习时间合计正式评分用时和关联知识/卡组的已完成专注，已绑定同一专注的评分不再重复累加。单次卡片用时最多记 10 分钟。它是应用内估算，不能替代系统级活动监测。
- 日复习上限按用户设置的时区结算。同一笔记的不同模板拥有独立记忆参数和稳定标识；明确重置才从新卡开始。

## 数据迁移与备份

IndexedDB V3 在原 journal 表之外新增独立的知识、块、卡组、笔记、卡片、复习日志、学习会话、关系、附件、规则和学习设置表。升级在版本事务中进行，保留 V2 成长快照。支持 V1/V2 JSON 和 V3 完整备份。

V3 JSON 包含附件的 Base64 数据，ZIP 使用独立二进制附件。导入前检查 Schema、父子循环、重复标识、主要引用、附件长度和 SHA-256；任何失败都在写入前或事务中回滚。合并时检测复习历史分叉，要求显式选择保留本地或导入状态，保留日志并排除未采用分支的统计。完全替换和清空需要确认。

加密备份复用 Web Crypto 的 AES-256-GCM、PBKDF2-SHA-256。密码仅用于本次操作；数据库本身保留浏览器的普通本地存储方式。JSON 单文件上限 200MB，CSV/Markdown 导入上限 20MB，单张图片上限 10MB。大批图片建议用 ZIP。

## 安装与离线

首次在线打开生产版本并完成缓存后，可离线重开所有页面，包括首次进入 MEMORIA、公式字体和代码高亮。通过设置中的安装入口或浏览器菜单安装 PWA。提醒仅在应用打开时检查，系统通知依赖授权。持久存储是否获批由浏览器决定，仍应定期导出备份。应用不发送外部遥测；正文外链仅在你点击时打开，正文图片从本地附件加载。

## 当前边界

- APKG、Obsidian 文件夹和 RemNote 原生包属于后续兼容项，当前请通过 CSV/Markdown 中转。
- Markdown 采用源码编辑与阅读预览，不是完整的所见即所得编辑器。图片宽度在插入前设置，说明文字可直接编辑。
- 知识图的拖动位置保留于当前页面会话，未做复杂自动布局或全库图谱渲染。
- 所有数据留在当前浏览器站点。跨设备使用备份迁移，没有自动云同步、AI 制卡或账号系统。
- 性能结果来自交付机器上的 Chromium 测试，不能保证低端手机或所有浏览器具有相同速度。详见 RELEASE_V3.md。
