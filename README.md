# NOCTURNE V2.0 · Ascension

本地优先的个人成长控制台。从每日行动、专注投入、量化进度，到长周期目标、编年史和复盘。日常使用不需要账户或后端。

## 在 Windows 本地打开

需要 Node.js 22.12 或更新版本。工作区已安装依赖时可跳过第一条。

```powershell
npm ci
npm run build
npm run preview -- --host 127.0.0.1 --port 5173 --strictPort
```

打开 [NOCTURNE](http://127.0.0.1:5173/)。使用和旧版相同的协议、主机与端口可以读取原有记录。开发模式使用 `npm run dev`。

## 从日常行动到长期目标

| 模块 | V2.0 功能 |
| --- | --- |
| 今日与日历 | 二值或量化打卡、最低标准、部分完成、跳过原因、弹性周次数、暂停区间、恢复、按例行组合筛选、历史补卡 |
| 人生领域 | 自定义领域与例行组合，查看关联习惯、目标、30 日完成趋势与专注时间 |
| 目标树 | 上级目标、前置依赖、真实行动进度与自定义里程碑 |
| 专注 | 25 分钟等番茄模式、正计时、任务名称、关联习惯与目标、沉浸计时、环境音、跨刷新恢复 |
| 洞察 | 原有完成率、排序与热力图，增加近四周稳定性、连续缺做、投入分配、常见执行时段、同期同比和环比、双习惯关联 |
| 成长编年史 | 从达标记录、目标与专注会话生成轨迹，添加个人事件并按年份、领域及类型筛选 |
| 复盘 | 日、周、月、季、年五种本地报告，含可编辑反思 |
| 命令中心 | Ctrl+K 或 ⌘K 搜索操作、习惯、目标与页面，支持方向键和 Enter |
| 设置 | Gothic 古铜、午夜蓝与墨黑主题，减少动效、收起导航、PWA 安装、普通或加密备份 |

## 数据口径

- 量化打卡达到最低标准后计为完成。修改标准只影响之后录入或编辑的记录。已排定的暂停日不计入计划，临时跳过计入未完成。下调暂停结束时间时保留旧日期的实际暂停记录。
- 弹性周目标按已达标日期及时累计。周结算后将未完成次数计到该周末尾的非暂停可执行日，同一日仅计一次。超额打卡按实际完成次数计入。未结算的周完成率不包含尚未分摊的弹性次数。周起始日依据本人设置。
- 连续全勤适用计划日。单个目标的进度取关联习惯记录。有里程碑时行动占 75%，里程碑占 25%。前置目标阻止下游目标达成。
- 领域时间使用会话记录的领域，早期未明确分配的专注回溯其习惯或目标。计时暂停期间不计正计时。正计时单次最多累计 24 小时。
- 关联使用共同计划日的二元达标状态，至少需要 7 个样本及两项状态的变化。时段图描述历史打卡分布，排除补卡。

## 从 V1.0 升级

IndexedDB 按版本事务迁移，兼容 V1 JSON 备份。恢复时先校验备份，再选择按更新时间合并或完全替换。不可逆的清空和替换需要确认。

加密导出使用浏览器 Web Crypto API，采用 AES-256-GCM 和 PBKDF2-SHA-256，密码仅用于本次操作。加密文件恢复需要原密码。它保护导出文件，应用本地数据库保留原有存储方式。

应用打开时检查提醒，系统通知依赖浏览器授权。离线重开需要生产版首次加载并完成缓存。在支持安装的浏览器中，从「设置 → 安装与离线」或浏览器菜单安装。用户数据归属当前浏览器站点地址，换设备、地址或配置文件时通过备份迁移。

## 工程与验收

```powershell
npm run lint
npm run typecheck
npm run test
npm run build
npx playwright install chromium
npm run test:e2e
```

React、TypeScript、Vite、Dexie、Zod 与 Motion。业务规则集中在 `src/core`，跨页面共享 IndexedDB 数据订阅，非首页路由按需加载。编年史使用窗口化渲染，滚动时只挂载视口附近的事件。

沿用 Astryx 的 Gothic 视觉方向，建立独立的古铜暗色配色。 [Astryx 主题](https://astryx.atmeta.com/docs/theme)
